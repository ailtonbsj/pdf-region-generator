crop_free

Seleção de Regiões

Carregue qualquer PDF e arraste para delimitar regiões com nome personalizado.

code

Geração de Código

Cada região gera um snippet Java stripper.addRegion(...) com coordenadas em pontos (pt).

content_copy

Cópia Automática

Ao gerar o código, ele é copiado para a área de transferência automaticamente.

zoom_in

Zoom de Alta Qualidade

Use +/−, Ctrl+scroll ou Ctrl+/Ctrl− para ampliar. O PDF é re-renderizado em cada nível, sem perda de qualidade.

Exemplo de saída
stripper.addRegion("cabecalho", new Rectangle(36, 28, 523, 60)); stripper.addRegion("data", new Rectangle(400, 100, 160, 20)); stripper.addRegion("assinatura", new Rectangle(36, 680, 200, 40));
