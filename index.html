Sobre
Informações sobre o aplicativo.
crop_free

Seleção de Regiões

Carregue qualquer PDF e clique e arraste sobre a primeira página para delimitar regiões de interesse com nome personalizado.

code

Geração de Código

Cada região gera automaticamente um snippet Java no formato stripper.addRegion(...) com coordenadas em pontos (pt).

content_copy

Cópia Automática

Ao clicar em "Gerar código", todo o trecho é copiado para a área de transferência automaticamente.

palette

Visualização

Cada região recebe uma cor distinta e exibe seu nome centralizado diretamente sobre o PDF, facilitando a identificação.

Exemplo de saída
stripper.addRegion("cabecalho", new Rectangle(36.0, 28.0, 523.0, 60.0)); stripper.addRegion("data", new Rectangle(400.0, 100.0, 160.0, 20.0)); stripper.addRegion("assinatura", new Rectangle(36.0, 680.0, 200.0, 40.0));
